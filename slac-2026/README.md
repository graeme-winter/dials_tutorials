# DIALS Tutorials with the Workflow GUI (SLAC 2026)

These tutorials are GUI-based versions of two of the [CCP4 / DLS 2024](../ccp4-dls-2024/README.md) tutorials, using the DIALS Workflow GUI in place of the individual command-line programs. The GUI builds and runs the same `dials.*` commands and writes the same files, so the two sets of tutorials can be used side by side.

- [Simple insulin to learn the workflow](./WORKFLOW.md) - import through merge on a single data set, one GUI step at a time
- [Cows, pigs and people](./COWS_PIGS_PEOPLE.md) - multi-crystal processing, symmetry determination with `dials.cosym` and isomorphism clustering with `dials.correlation_matrix`, first on the cows-only data and then on the full cows / pigs / people mixture, both through the GUI

The screenshots were taken with DIALS 3.30. Images shared with the 2024 tutorials are linked from `../ccp4-dls-2024/images/` rather than duplicated.
